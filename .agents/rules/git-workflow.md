# Git Commit and Push Rule

## Rule
- **DO NOT** execute `git commit` or `git push` automatically after making edits or building code.
- **ONLY** execute `git commit` and `git push` when the user explicitly instructs you to do so (e.g., "commit the changes", "push it", "commit and push").
- Leave all modified files in the local working directory until explicit user request to commit or push.

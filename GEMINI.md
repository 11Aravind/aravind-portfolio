# Git Commit & Push Protocol

## Explicit User Approval Required
- **NEVER** run `git commit` or `git push` automatically after making edits or building.
- **ONLY** run `git commit` and `git push` when the user explicitly instructs you to commit or push (e.g., "commit this", "push to github", "commit and push").
- Keep all modifications in the local working directory until the user gives explicit command/permission to commit and push them.
